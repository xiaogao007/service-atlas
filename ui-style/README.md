# 浅色工作台 · Light Workspace

可复用 UI 风格包，版本 1.0，提炼日期 2026-10-09。

这套风格用浅灰导航、白色内容、深灰主动作、细边框和分级圆角建立层级。淡彩只用于小面积图标与语义状态；右侧面板围绕当前任务提供详情、引导或辅助操作。适用于管理后台、SaaS、资源台账、内容管理和工作工具。

## 包内文件与使用方式

| 文件 | 用途 |
| --- | --- |
| [theme.css](theme.css) | 可直接复制的 CSS 设计变量，无依赖 |
| [PROMPT.md](PROMPT.md) | 给设计师或 AI 的复用提示词，填写产品信息后使用 |
| [reference.jpg](reference.jpg) | 当前实现的桌面视觉参考，业务内容仅作示意 |
| 本文件 | 布局、组件、状态、迁移与验收规范 |

![浅色工作台视觉参考](reference.jpg)

将整个 `ui-style/` 目录复制到目标项目，阅读规范和提示词，再把 `theme.css` 接入项目唯一的主题入口。新项目可以把本规范整理进自己的 `DESIGN.md`；已有设计规范的项目合并相关章节，记录明确采用的规则。

`theme.css` 只声明变量和浅色 `color-scheme`，不会自动生成组件、布局、滚动条或交互。目标项目的共享组件需要消费这些变量。按钮、表单、弹窗和表格优先沿用已有组件，集中映射主题，避免每个页面分别写颜色与状态。

```css
/* 先加载 theme.css，再由项目共享组件消费变量。 */
.workspace {
  font-family: var(--font);
  font-size: var(--text-body);
  line-height: 1.6;
  color: var(--ink);
  background: var(--canvas);
}
.card {
  padding: var(--space-5);
  border: 1px solid var(--line);
  border-radius: var(--radius-card);
}
```

## 风格签名

- **灰阶骨架**：导航浅灰、主区白底；正文、次要信息、辅助说明各有稳定文字层级。
- **清楚的主动作**：主要按钮使用深灰实底白字，普通操作使用白底边框或文字按钮。
- **轻边界**：卡片默认无阴影，依靠 1px 边框和留白区分对象。
- **分级圆角**：控件 10px、分段项 12px、卡片 16px、弹窗 24px。
- **少量淡彩**：蓝、紫、桃、绿点缀对象图标；状态色表达结果并配合文字。
- **上下文辅助**：右侧详情跟随所选对象，帮助完成当前任务；内容与产品业务相符。

整体偏紧凑、平静、易扫读。避免用满屏彩色指标卡、厚重阴影、装饰性渐变、巨大留白或过度动效改变这套风格。

## 颜色与语义

颜色值以包内 `theme.css` 为准，下表列出主要映射。

| 角色 | CSS 变量 | 值 | 使用场景 |
| --- | --- | --- | --- |
| 内容底色 | `--canvas` | `#FFFFFF` | 主区、卡片、表单、弹窗 |
| 次级底色 | `--surface` | `#F7F7F7` | 导航、搜索、分段容器 |
| 轻底色 | `--surface-subtle` | `#FAFAFA` | 表头、行悬停、只读内容 |
| 悬停底色 | `--surface-hover` | `#F1F1F1` | 图标按钮等轻控件 |
| 导航选中底色 | `--surface-selected` | `#EAEAEC` | 导航图标容器 |
| 正文 / 主动作 | `--ink` / `--primary` | `#262626` | 正文、标题 / 主按钮，保持语义变量分别存在 |
| 次要文字 | `--secondary` | `#595959` | 字段值、次要操作 |
| 辅助文字 | `--muted` | `#737373` | 描述、时间、占位提示 |
| 常规边框 | `--line` | `#EBEBED` | 卡片、表格、分隔线 |
| 控件边框 | `--line-strong` | `#DEDEE2` | 输入框、次级按钮 |
| 悬停边框 | `--line-hover` | `#C6C6CB` | 可操作卡片、按钮 |
| 主按钮悬停 | `--primary-hover` | `#404040` | 深灰主按钮 |
| 正向结果 | `--success` / `--success-bg` | `#26764C` / `#EFF7F1` | 已完成、正常、成功 |
| 注意条件 | `--warning` / `--warning-bg` | `#94651D` / `#FCF5E8` | 需关注、可恢复风险 |
| 失败 / 危险 | `--danger` / `--danger-bg` | `#AD403A` / `#FDF0EF` | 明确失败、最终危险确认 |
| 键盘焦点 | `--focus` | `#386FC0` | 可见焦点环，与品牌色分开 |

淡彩对象图标使用成对变量：

| 色组 | 图标色 | 背景色 |
| --- | --- | --- |
| Blue | `--blue: #5B80AE` | `--blue-bg: #ECF3FB` |
| Lavender | `--lavender: #8C77B3` | `--lavender-bg: #F1EDFA` |
| Peach | `--peach: #BB8666` | `--peach-bg: #FFF0E8` |
| Sage | `--sage: #7A9582` | `--sage-bg: #EDF4EF` |

淡彩用于辨认对象，不承载关键正文或状态含义。状态必须同时有文本；未知、未获取、处理中分别描述，不能用失败色推断未知结果。颜色迁移后在实际背景上检查文字、焦点和控件对比度。

## 字体、间距与形状

使用系统字体，避免依赖远端字体加载。默认中文 / 拉丁文字栈为 `--font`；代码、编号、地址或技术值按需使用 `--mono`，普通业务文案使用正文字体。

| 层级 | 字号 / 字重 | 行高或用途 |
| --- | --- | --- |
| 页面标题 | 24px / 650 | 1.45，页面级身份 |
| 区块标题 | 18px / 600 | 28px，列表分组 |
| 卡片名称 | 16px / 600 | 明确对象名称 |
| 正文、表格主信息、标准控件 | 14px / 400–500 | 正文 1.6 |
| 辅助信息、紧凑控件、技术值 | 12px / 400 | 关键说明至少 12px；长技术内容可换行或内部滚动 |

间距使用 `4 / 8 / 12 / 16 / 20 / 24 / 32px`。页面桌面内边距 24px，卡片内边距 20px，卡片间距 16px，区块间距 24–32px。表单字段间距 16px，标签到输入框约 6px。

标准控件高度 40px；桌面紧凑控件 32px。触屏主要动作优先使用标准尺寸并按目标平台扩展命中区，不为紧凑外观牺牲可操作性。

圆角由对象层级决定：控件 10px、分段项 12px、卡片 16px、弹窗 24px。小状态标签可用 6px；头像和状态点可用圆形。图标采用一套一致的线性图标，常规 20px、按钮内 16px、描边约 1.7px。

## 布局与响应式

默认桌面工作台：

```text
┌──────┬─────────────────────────────────┬───────────────────┐
│ 72px │ 分段导航 / 页面工具栏            │ 当前任务的上下文  │
│ 导航 ├─────────────────────────────────┤ 详情 / 引导       │
│      │ 标题 + 描述 + 主要动作           │ 辅助信息 / 操作   │
│      │ 搜索与筛选                       │ 默认 400px        │
│      │ 卡片 / 表格 / 表单               │                   │
│      │ 后续内容                         │                   │
└──────┴─────────────────────────────────┴───────────────────┘
```

主内容左对齐，宽度自适应；容器使用 `minmax(0, 1fr)` / `min-width: 0` 防止长内容撑宽。导航只放主要模块，图标配简短文字。页头集中放标题、说明和主要动作；搜索及筛选靠近结果。

| 视口 | 当前风格的参考策略 |
| --- | --- |
| ≥1600px | 主内容最大宽度 1240px，页内边距可到 40px，适合三列卡片 |
| 1280–1599px | 72px 导航 + 自适应主区 + 400px 上下文栏，通常两列卡片 |
| 1151–1279px | 上下文栏缩为 360px |
| 701–1150px | 默认收起右栏，选中对象后按需打开可关闭的详情侧栏 |
| ≤700px | 60px 导航、16px 页面水平内边距、单列卡片；详情占导航外的可用宽度 |

这些是风格的参考参数。数据列很多或模块名称很长时，可按目标产品任务调整导航形式、上下文宽度和断点，保持文字层级、颜色和组件语义一致。没有辅助任务的页面允许只保留导航和主区。

主内容采用文档自然纵向滚动，导航和桌面右栏粘附；右栏长内容独立滚动。宽表格只在自身区域横向滚动。不要为某一张表给所有页面或长表单设置固定高度、隐藏溢出。

## 组件配方

| 组件 | 视觉配方 | 交互约束 |
| --- | --- | --- |
| 主按钮 | 深灰底、白字、40px 高、10px 圆角 | 清楚的动词；hover、focus、pressed、disabled、busy 都有表现 |
| 次级 / 文字按钮 | 白底细边框 / 无边框次要文字 | 与主按钮同一字号和圆角体系 |
| 搜索框 | 浅灰底、40px 高、12px 圆角、左侧搜索图标 | 有值时提供可访问的清除按钮；中文输入法合成不提前触发 |
| 输入框 | 白底、强边框、10px 圆角 | 标签、说明、内联错误；错误后保留输入 |
| 分段导航 | 浅灰容器、4px 内边距、白色选中项、12px 项圆角 | 路由用链接；结果筛选用按钮；真正 tabs 使用完整键盘模型 |
| 对象卡片 | 白底、1px 边框、16px 圆角、20px 内边距、无常驻阴影 | 对象名先于元数据；可点击卡片有焦点和边框悬停变化 |
| 数据表 | 16px 圆角外壳、浅灰表头、轻行分隔、14px 主信息 | 语义 table；分页、筛选、选中范围按数据契约设计 |
| 状态标签 | 12px 文字、小圆角、浅底 + 深色文字 | 状态文字与颜色一起出现；跨页面同义同色 |
| 上下文面板 | 白底、细左边框、内容分组；可选极淡顶部光晕 | 明确所选对象；窄屏可关闭；区分模态和非模态 |
| 弹窗 | 白底、24px 圆角、26px 内边距、轻遮罩、统一浮层阴影 | 标题、描述、动作；焦点进入与恢复、Escape、长内容可滚动 |
| Toast / 持续反馈 | 深灰浮动提示 / 浅色内联提示 | Toast 仅确认结果，关键失败保留在相关页面或字段 |
| 空 / 无结果 / 错误 | 小图标、直接说明、一个可执行下一步 | 区分首次无数据、搜索无匹配、请求失败 |

普通卡片无阴影。浮层阴影使用 `--shadow-overlay`，临时详情侧栏使用 `--shadow-drawer`；`--shadow-tip` 和 `--context-glow` 是可选辅助装饰，不扩散到全部页面。

只保留响应用户操作的短过渡，基线 `--motion: 160ms`；优先过渡背景、边框和颜色。尊重 `prefers-reduced-motion`，减少或关闭动效。滚动条全局统一，保持可见并支持强制颜色模式。

## 通用交互与文案

相同动作在不同页面使用相同名称、组件、反馈与取消方式。按钮写“保存修改”“创建项目”“导出记录”等实际动作；反馈复用同一动作词。说明和错误直接交代对象、原因和下一步。

表单自有内联验证，提交失败保留输入并定位首个错误，提交中阻止重复执行。未保存内容离开前有可靠保护。敏感字段默认遮蔽；正常可逆保存不额外加确认。

加载、后台刷新、空数据、无匹配、失败、禁用和成功各有对应表现；按钮忙碌、提示插入、异步内容和字体加载不挤动主要操作。危险操作按目标产品的实际后果决定确认级别，最终确认明确对象、范围和动作。

搜索和筛选保留用户上下文；允许分享的状态可写入 URL，表单草稿和敏感信息不写入 URL。远程请求处理过期响应，远程搜索可采用约 300ms 防抖；清除和显式提交即时执行。

详情面板默认可采用非模态模式并保留背景可操作性；需要阻断流程时使用真实模态机制。两者按组件契约处理焦点，不能仅用遮罩制造模态外观。

全部可操作元素保留语义、键盘支持和可见焦点；图标按钮有可访问名称。时间、数字、文案和读屏标签使用目标产品语言与时区。迁移完成后以目标产品支持范围核验对比度、窄屏、长文本和键盘操作。

## 跨产品迁移边界

**稳定复用**：灰阶基础、语义色、文字层级、间距节奏、分级圆角、轻边框、按钮强调关系、反馈和输入状态。

**按任务调整**：模块名称、导航宽度、卡片字段、表格列、分页、面板内容、插画、对象图标、空状态、断点与信息密度。信息密集产品可强化表格，任务型产品可强化列表或表单。

**由目标产品定义**：权限、身份与数据生命周期、支付与隐私、危险操作、删除与撤销、持久化、数据来源、失败恢复及异步任务状态。服务地图的服务器、日志、端口、重启与未知结果规则不属于通用风格包。保留右侧上下文结构也不意味着必须添加 AI 助手。

若使用现有组件库，将其主题中的主色、背景、文字、边框、字号、控件高度、圆角、焦点和浮层映射到对应语义变量；禁用、验证、弹窗和键盘行为继续由共享组件负责。不要把同值的 `--ink` 和 `--primary` 合并成一个含糊的角色。

## 完成检查

迁移时至少检查一个列表页、一个详情或编辑流程、一个弹窗和一个空 / 错误状态；同时核对桌面与手机。

- 主次动作、文字和圆角在所有页面一致；没有页面私有色板。
- 长对象名、窄屏、宽表格和长表单都能完整访问。
- hover、focus、disabled、busy 和结果反馈可辨识；关键说明不会仅靠颜色。
- 搜索清除、表单错误恢复、取消、返回、未保存保护和弹窗焦点符合共享契约。
- 图标、文案、状态含义以及语言 / 时间格式围绕目标产品任务。

## 来源与维护

本包从用户已确认的 Service Atlas 实现提炼，导出时的源码提交为 `183a73ffd0942971d1a98ad02092adf12807dd27`。颜色和变量来自 `ui-prototype/dist/theme.css`；布局和组件参数来自 `ui-prototype/dist/styles.css` 与完整产品设计规范。

在本仓库，原型 `theme.css` 继续作为运行时唯一来源，包内 `theme.css` 是字节一致的导出快照，不被当前页面加载。基线变化时重新复制源文件并核对本规范、提示词和参考图。复制到其他项目后，目标项目选定自己的唯一主题来源，记录经批准的适配，避免维护两套独立色值。

此包提供风格与行为约定，未提供框架组件库、暗色模式或其他产品的适配实现；原始实现的业务数据仍为模拟。
