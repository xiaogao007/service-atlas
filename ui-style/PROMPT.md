# 复用提示词：浅色工作台

使用前把本文件与同目录的 `README.md`、`theme.css`、`reference.jpg` 一起提供给设计师或 AI，填写下列方括号。参考图用于视觉校准，内容按目标产品替换。

```text
请将当前产品的 UI 按附件“浅色工作台 · Light Workspace”规范升级，并直接完成实现。

产品：[产品名与一句话定位]
用户：[主要用户与使用设备]
主要任务：[最重要的 2–3 个任务]
范围：[需要改造的页面和流程]
技术栈：[现有框架与组件库]
语言与时区：[例如 zh-CN / Asia/Shanghai]
业务约束：[必须保留的流程、权限、数据行为与危险操作规则]

先阅读项目的业务文档、DESIGN.md、共享组件、主题与相关流程，确认改造范围；优先复用已有组件和真实数据接入。视觉依据为附件的规范、theme.css 和参考图。所有调整集中在共享主题与组件，覆盖列表、详情、表单、弹窗、空状态和异常反馈。

风格签名：浅灰窄导航、白色主工作区、深灰主按钮、细边框、分级圆角、少量淡彩图标，以及围绕当前任务的可选上下文面板。保持信息紧凑、文字清楚、主次动作明确。

基础色：内容 #FFFFFF、次级底色 #F7F7F7；正文与主动作 #262626，次要文字 #595959，辅助文字 #737373；常规边框 #EBEBED，控件边框 #DEDEE2；键盘焦点 #386FC0。成功、警告和失败使用 theme.css 的语义色，并同时展示文字。

字号：页面标题 24px/650，区块标题 18px/600，卡片名称 16px/600，正文与标准控件 14px，辅助信息 12px；系统字体，正文行高 1.6。技术值按需使用等宽字体。

尺寸：控件高 40px，紧凑控件 32px；圆角控件 10px、分段项 12px、卡片 16px、弹窗 24px；页面桌面内边距 24px、卡片内边距 20px、卡片间距 16px。普通卡片无常驻阴影。

布局默认参考 72px 导航 + 自适应内容 + 400px 上下文栏；1151–1279px 右栏 360px，1150px 以下默认收起并按需打开，700px 以下使用 60px 导航、16px 页面水平内边距和单列内容。允许按产品信息密度调整导航形式与断点，保持视觉签名。表格内部横向滚动，长表单完整可达。

统一 hover、focus-visible、pressed、disabled、busy；保留搜索清除、中文输入法安全、表单内联错误和输入恢复、未保存保护、弹窗焦点恢复、可靠的取消和返回。关键状态与错误不能只存在于 Toast。按真实产品后果设计危险确认；加载反馈真实且不引起布局跳动。

替换产品名称、数据、图标、插画和面板文案。依据目标产品定义权限、生命周期与业务状态。不要沿用服务地图的服务器、重启或演示数据规则，也不要仅因参考图有辅助面板而添加 AI 功能。避免满屏彩色卡片、厚阴影、装饰性渐变、巨大标题与过度动效。

完成后更新项目 DESIGN.md 与共享交互契约，说明主题唯一来源和组件映射。验证代表性列表、详情/编辑、弹窗、空/错误状态、桌面和手机、长文本、键盘与减少动效设置，并运行与变更相关的项目检查。提供可查看的运行结果和改动摘要。
```

已有项目需按明确范围迁移共享主题和完整流程；新项目先确定业务任务和信息结构，再应用同一套视觉与交互规则。
