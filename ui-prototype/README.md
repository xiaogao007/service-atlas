# 服务地图 UI 交互原型

采用用户确认的浅色工作台 UI 基线，统一产品、待整理、服务器、操作历史、设置和服务详情。主题值位于 [theme.css](dist/theme.css)，规范见 [DESIGN.md](DESIGN.md)。使用虚构产品与示例网段演示核心交互，纯 HTML、CSS、JavaScript，无构建依赖。

## 本地查看

在本目录运行 `python -m http.server 4173 --bind 127.0.0.1 --directory dist`，打开 `http://127.0.0.1:4173`。

## 可以体验

- 新建与编辑产品，按服务器筛选，通过端口、域名、目录反查服务。
- 产品详情与服务侧栏，切换概览、入口、日志和操作。
- 待整理资源单条或多条关联产品，保留跨服务器独立身份。
- 查看日志、切换来源、开始和暂停模拟跟随。
- 预览重启，模拟恢复成功、健康检查失败和连接中断；核验与解锁未知结果。
- 服务器状态、模拟接入与指纹确认、刷新盘点、按结果筛选操作历史、台账导出。

所有修改仅在当前页面会话生效，刷新重置。原型不连接服务器、不收集凭据，也不执行真实重启。

## 验证

`npm run check` 检查 JavaScript 语法，`npm test` 核对跨主机端口查询、原子归属关联与重启阻断。视觉与浏览器交互核对见 [browser-verification.md](browser-verification.md)。
